# Cloud-Native Online Examination System Using AWS

## Project Overview
This project explores a serverless online examination system designed to deliver questions, process student submissions and calculate examination scores.

## Technology Stack
The original project describes an architecture using:
- Amazon S3 and CloudFront
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon CloudWatch
